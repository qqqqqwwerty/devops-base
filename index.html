О проекте

DevOps Base представляет собой полноценный инфраструктурный проект, демонстрирующий современные практики контейнеризации, оркестрации, мониторинга и безопасности. Проект разработан как портфолио для демонстрации практических навыков DevOps-инженера и готовности к решению реальных производственных задач.

Ключевые возможности

  • Multi-container приложение с Docker Compose
  • Полноценные Kubernetes манифесты для production
  • Автоматизированный CI/CD пайплайн с GitHub Actions
  • SSL/TLS шифрование с Let's Encrypt
  • Комплексный мониторинг (Prometheus + Grafana + Alertmanager)
  • Telegram-уведомления для алертинга
  • Network isolation и security headers
  • Автоматизация деплоя через shell-скрипты

Архитектура системы

Проект реализует современную архитектуру с разделением на frontend и backend сети, изоляцией сервисов и полноценным мониторингом. Все компоненты контейнеризированы и готовы для развертывания как в Docker Compose, так и в Kubernetes кластере.

Мониторинг и алертинг

Встроенная система мониторинга обеспечивает полный контроль над состоянием всех сервисов с возможностью реальных уведомлений через Telegram при возникновении проблем. Prometheus собирает метрики каждые 15 секунд, Grafana предоставляет визуализацию, а Alertmanager маршрутизирует алерты.

Безопасность

Проект включает современные практики безопасности: SSL/TLS шифрование с автоматическим обновлением сертификатов, управление секретами через Kubernetes Secrets, network isolation для разделения сетей, security headers для защиты от распространенных уязвимостей.
